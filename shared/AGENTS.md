# Global Agent Instructions

## Communication

- ユーザーが日本語で書いたら日本語で回答する
- ユーザーが英語で書いたら英語で回答する
- 技術用語はそのまま（翻訳しない）

## Code Style

- **最小変更**: タスクに必要な範囲だけ変更する。スコープ外のリファクタはしない
- **既存パターン踏襲**: 新しいコードはそのファイルの既存スタイルに合わせる
- コメント・docstring・型アノテーションは変更したコードにのみ追加する
- コメントは自明でないロジックにのみつける

## Security

- 認証情報・機密情報（.env・鍵ファイル等）を git commit しない
- 外部入力を扱うコードでは、SQL はプレースホルダ、シェル実行は引数配列、HTML 出力はエスケープを使う

## Git

- コミット・push は明示的に依頼されたときのみ実行する（手順は `commit-pr` スキル）
- 既存のコミットは amend しない、force push しない
